# NEBULA SECRET — Wholesale Product Catalog

An English B2B wholesale product catalog curated from Alibaba.com, built as a static single-page site.

- **476 products** across Makeup, Skincare, Fragrance & Aromatherapy, Pet Supplies, Electronics and Sports
- Search by name / description / category, filter by category & sub-category, sort by price or name
- Delete unwanted products on any device (remembered in local storage, with "Restore all")
- NEBULA SECRET logo watermark on every card

## Files

| Path | Description |
|---|---|
| `index.html` | The site (self-contained HTML + inline CSS/JS) |
| `company_logo.png` | Brand logo |
| `images/` | Makeup + skincare product images (001–110) |
| `images_pet/` | Pet product images (001–133) |
| `images_elec/` | Electronics product images (001–100) |
| `images_frag/` | Fragrance & aromatherapy product images (001–100) |
| `images_sport/` | Sports product images (001–100) |

## Run locally

Open `index.html` in any browser (no server needed).

## Deploy to GitHub Pages

1. Push this repository to GitHub (e.g. with GitHub Desktop).
2. In the repo on github.com: **Settings → Pages → Source: Deploy from a branch → Branch: `main` → `/ (root)` → Save**.
3. Your site will be live at `https://<username>.github.io/<repo-name>/` after the first build (~1 min).

> Products, prices, MOQ and links were collected from Alibaba.com (International) on 2026-09-09. Prices are estimates converted from HKD (÷7.8); confirm with suppliers before ordering.
