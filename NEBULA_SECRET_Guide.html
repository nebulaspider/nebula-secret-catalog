Browse & Search

瀏覽與搜尋

Find any product in seconds

The search box works on product name, description and category — English keywords only, e.g. serum, cat litter, earbuds. Use the category buttons (8 colored categories) and the sub-category chips (e.g. Serum, Scented Candles, Wireless Earbuds) to narrow the grid. The counter above the grid shows how many products match.

  1. Type in the top search bar, or the one inside the hero section.
  2. Click a category chip — the grid filters instantly.
  3. Click a sub-chip for a narrower view (e.g. Makeup → Lip Set).

秒速找到想要的產品

搜尋框會同時搜尋產品名稱、描述與分類，請用英文關鍵字，例如 serum（精華）、cat litter（貓砂）、earbuds（耳機）。上方的 8 個彩色分類按鈕與「子分類」標籤（如 Serum、Scented Candles、Wireless Earbuds）可進一步縮窄範圍，網格上方會顯示符合的產品數量。

  1. 在頂部或首頁區的搜尋框輸入關鍵字。
  2. 點擊分類按鈕，產品即時篩選。
  3. 再點子分類，例如 Makeup → Lip Set 只顯示唇部組合。

Category colors

分類配色 — 一眼分辨

Every category has its own color

Each category uses a signature color in three places: the badge on the product photo, a 4px border on top of every card, and a dot on its category button. When a category is selected, the whole chip fills with that color. This makes different product types instantly recognizable.

每個類別都有自己的顏色

每個類別都用一個專屬顏色，出現在三個地方：產品照片上的類別標籤、每張卡片頂部的 4px 色條、以及分類按鈕上的圓點。選中某個分類時，整顆按鈕會填滿該類別的顏色，一眼就能分辨產品類型。

Sort products

排序

Sort the way you need

The Sort menu offers: Featured (default), Price: low → high, Price: high → low, and Name: A → Z. Sorting always applies to the currently filtered view.

依需求排序

Sort 選單提供：Featured（精選，預設）、價格由低到高、價格由高到低、名稱 A → Z。排序只會套用在目前篩選後的產品上。

Currency — “Price in”

20 種貨幣價格轉換

View every price in 20 currencies

Open the Price in menu (e.g. USD — United States) and pick any of the 20 currencies — USD, EUR, GBP, HKD, CNY, JPY, KRW, AUD, CAD, SGD, NZD, CHF, SEK, THB, MYR, PHP, INR, IDR, AED, VND. All prices on the page convert instantly (using fixed approximate rates from 2026-09-10), and your choice is remembered on this device.

一鍵切換 20 種貨幣

打開 Price in 選單（例如 USD — United States），可選擇 20 種貨幣——USD、EUR、GBP、HKD、CNY、JPY、KRW、AUD、CAD、SGD、NZD、CHF、SEK、THB、MYR、PHP、INR、IDR、AED、VND。頁面上所有價格即時換算（採用 2026-09-10 固定近似匯率），且選擇會記住，下次開啟仍然保留。

Note 注意：Rates are fixed estimates for reference — confirm the live rate with your bank or supplier. / 匯率為固定參考值，請以銀行或供應商當日匯率為準。

Link health check

連結檢查 — 失效自動調暗

Dead links are dimmed automatically

When the page loads, every product link is tested in the background. A product whose link is unreachable is dimmed (grey and faded) with an “Link unavailable” tag, so you never send a broken link to a customer. Click Recheck links to test everything again. Results are cached for 24 hours.

失效連結會自動變暗

頁面載入時會於背景逐一測試每個產品連結。無法開啟的產品會變暗（灰化）並標示「Link unavailable」，確保你不會把壞連結發給客戶。按 Recheck links 可重新檢查全部，結果會快取 24 小時。

Select products

勾選產品

Build your shortlist

Tick the checkbox on any card to add it to your selection — the card gets a green border. Use Select all to pick every product in the current view, or Clear to reset. The Quote & Export button shows how many products you have selected. Your selection is remembered on this device.

建立你的候選清單

點卡片右上角的勾選框即可加入選擇，卡片會出現綠色邊框。按 Select all 全選目前視圖中的產品，Clear 清除選擇。Quote & Export 按鈕會顯示已選數量，選擇會自動記住。

Customer Quotation

報價單 — 每類別折扣／加價

Set discount or markup per category

Click Quote & Export to open the quotation page. It shows:

  • Global adjustment — one number applied to every category.
  • Per-category % — e.g. Makeup -10 (discount) or Electronics +15 (markup).
  • A live table of your selected products: Base price → Adj % → Final price, with totals (Base / Final / Adjustment).

Positive numbers = markup, negative = discount. The final price = base price × (1 + global% + category%).

每個類別可獨立設折扣或加價

按 Quote & Export 開啟報價頁，包含：

  • Global adjustment 全局調整 — 一個數字套用所有類別。
  • 每類別 % — 例如 Makeup 填 -10（折扣）或 Electronics 填 +15（加價）。
  • 已選產品的即時表格：原始價 → 調整 % → 最終價，並顯示 Base / Final / Adjustment 總計。

正數代表加價、負數代表折扣。最終價 = 原始價 × (1 + 全局% + 類別%)。

Export 匯出

What the file contains

Each exported file includes: No., Category, Product Name, Description, MOQ, Base Price, Adj %, Final Price, the live Alibaba link — plus product photos (full-size when the page is online, thumbnails when opened offline). Excel opens in any spreadsheet app; PDF is ready to email to your customer as-is.

匯出檔包含什麼

匯出的 Excel 或 PDF 都包含：編號、類別、產品名稱、描述、MOQ、原始價、調整 %、最終價、Alibaba 產品連結，並附上產品圖片（線上開啟為原圖、離線開啟為縮圖），以及公司名稱、日期與貨幣的抬頭。Excel 可用任何試算表軟體開啟；PDF 可直接電郵給客戶確認。

Publish to GitHub Pages

上線部署

Go live in three steps

The site is ready to publish. You only need:

  1. Open GitHub Desktop and select the nebula-secret-catalog folder.
  2. Commit the changes (set your name/email if asked) and Push to the nebula-secret-catalog repo.
  3. Enable GitHub Pages for the repo (Settings → Pages → main branch). Your site goes live at https://nebulaspider.github.io/nebula-secret-catalog/.

三步驟上線

網站已準備好發布，你只需要：

  1. 開啟 GitHub Desktop，選擇 nebula-secret-catalog 資料夾。
  2. Commit 變更（如被要求設定姓名／電郵就填上），然後 Push 到同名 repo。
  3. 在 repo 的 Settings → Pages 開啟 GitHub Pages（選 main branch），網站即上線於 https://nebulaspider.github.io/nebula-secret-catalog/。
